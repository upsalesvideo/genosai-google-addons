# 🤖 ИИ агент Гено-Сай в Google Документах

Меню **🤖 Гено-Сай** → сайдбар с тремя вкладками:

- **Картинка** — промпт → картинка вставляется в место курсора;
- **Текст** — 23 текстовые модели (GPT-5.x, Claude, Gemini, DeepSeek, Perplexity) → ответ вставляется
  готовой разметкой: заголовки, списки, таблицы, жирный;
- **Шаблоны** — заготовки (КП, посты). Модель сама пишет документ **и сама расставляет в нём
  картинки**, скрипт их генерирует и вставляет на нужные места.

Всё через [Genosai Public API](https://api.genosai.io).

## Файлы

| Файл в Apps Script | Что внутри |
|---|---|
| `Code.gs` | меню, сайдбар, вставка картинки, ресайз, подпись, референсы, настройки |
| `genosai/service.gs` | API: ключ, `balance`, `models`, `createTask`, `taskInfo`, `uploads`, `chat/completions` |
| `doc/markdown.gs` | Markdown → документ (заголовки, списки, таблицы, жирный) + маркеры под картинки |
| `templates/store.gs` | шаблоны: хранение, подстановки `{{…}}`, запуск через текстовую модель |
| `Sidebar.html` | интерфейс: три вкладки, настройки, редактор шаблонов |
| `appsscript.json` | манифест: V8 + 3 OAuth-скоупа |

## Установка

1. Документ → **Расширения → Apps Script**.
2. **⚙ Настройки проекта** → включить показ `appsscript.json`.
3. Создать файлы с такими именами (**+ → Скрипт / HTML**) и вставить содержимое:
   `Code`, `genosai/service`, `doc/markdown`, `templates/store` (скрипты), `Sidebar` (HTML),
   плюс `appsscript.json`. Имена со слэшем редактор сам покажет папками.
4. Сохранить, один раз запустить `onOpen`, выдать разрешения.
5. Перезагрузить документ → в меню появится **🤖 Гено-Сай**.
6. Открыть сайдбар → **⚙** → вставить свой ключ Genosai (genosai.io → API) → «Сохранить ключ».

Ключ **не хранится в коде**. Он ложится в ваш личный профиль Google (UserProperties) и не виден
другим соавторам файла: каждый вводит свой. Если нужен общий ключ на всю команду — положите его
в **Настройки проекта → Свойства скрипта → `GENOSAI_API_KEY`**, он используется как запасной.

## Значения по умолчанию

Модель **ChatGPT Image 2**, качество **1K**, формат **16:9**, ширина в документе — **во всю страницу**.
Меняются в сайдбаре, при следующем открытии снова встают по умолчанию.

## Вкладка «Картинка»

- **＋ Добавить референс** — файл с компьютера. Сколько референсов принимает модель, берётся из API:
  nano-banana — 10, ChatGPT Image 2 — 16, z-image не принимает — и блок для неё скрыт.
- Галочка **«Плюс картинка, выделенная в документе»** — уже вставленная картинка уходит в
  `image_urls`, и модель переделывает её по промпту.
- Любой референс и результат открываются по клику в полноэкранном просмотре.

## Вкладка «Текст»

Модель, задание, галочка «учитывать выделенный текст» (перепиши, сократи, продолжи).
Для Perplexity появляется «искать в интернете». Ответ вставляется в место курсора уже
отформатированным.

## Вкладка «Шаблоны»

Шаблон = роль модели + задание с подстановками + настройки картинок.

- Подстановки пишутся двойными фигурными скобками: `Клиент: {{клиент}}` → в сайдбаре появляется
  поле «клиент».
- Если включено «модель сама расставляет картинки», к промпту добавляется правило вставлять маркеры
  `[[IMG: описание]]`; сайдбар генерирует картинку под каждый маркер и заменяет их в документе.
- Референс работает и здесь: загруженная картинка уходит во **все** иллюстрации документа.

Заводские шаблоны: **Коммерческое предложение** и **Пост в соцсети**. Хранятся в Script Properties
(`GENOSAI_TEMPLATES`), то есть живут вместе с документом.

## Сколько стоит

КП на две страницы через `gpt-5.4` — около 1 кредита. Картинки по прайсу модели:
ChatGPT Image 2 — 6 кр., nano-banana — 4 кр., z-image — 1 кр. Кредиты видно вверху сайдбара
и по кнопке **«Проверить кредиты»** в настройках.

## Ограничения

- Лимит выполнения Apps Script (6 минут) не задевается: статус генерации опрашивается с клиента.
- Видео-модели не выведены — Google Документ не умеет встраивать видео.
- Скоуп `documents.currentonly`: скрипт видит только тот документ, в который вшит.
