# 🤖 AI Agent GenosAI в Google Презентациях

Меню **🤖 AI Agent GenosAI** → сайдбар с тремя вкладками:

- **Картинка** — промпт → картинка раскладывается по слайду (на весь слайд, справа, слева, вписать),
  на текущий или на новый слайд;
- **Стиль** — визуальный выбор стиля карточками. Стиль подмешивается в **каждую** генерацию,
  поэтому слайды выглядят как одна презентация;
- **Презентация** — тема → модель раскладывает её на слайды → **вы правите текст прямо в сайдбаре** →
  подтверждаете → скрипт создаёт слайды и рисует картинки в выбранном стиле.

## Файлы

| Файл в Apps Script | Что внутри |
|---|---|
| `Code.gs` | меню, сайдбар, настройки, серверные `ui*`-функции |
| `genosai/service.gs` | API: ключ, `balance`, `models`, `createTask`, `taskInfo`, `uploads`, `chat/completions` |
| `slides/insert.gs` | геометрия раскладок, создание и удаление слайдов, плашка с заголовком, референс со слайда |
| `style/store.gs` | стили: хранение, подмешивание в промпт, эталоны |
| `deck/plan.gs` | план презентации от текстовой модели + разбор JSON |
| `Sidebar.html` | интерфейс: три вкладки, карточки стилей, редактор плана |
| `appsscript.json` | манифест: V8 + 3 OAuth-скоупа (`presentations.currentonly`) |

## Установка

1. Презентация → **Расширения → Apps Script**.
2. **⚙ Настройки проекта** → включить показ `appsscript.json`.
3. Создать файлы с такими именами и вставить содержимое: `Code`, `genosai/service`, `slides/insert`,
   `style/store`, `deck/plan` (скрипты), `Sidebar` (HTML), плюс `appsscript.json`.
4. Сохранить, один раз запустить `onOpen`, выдать разрешения.
5. Перезагрузить презентацию → в меню появится **🤖 AI Agent GenosAI**.
6. Открыть сайдбар → **⚙** → вставить свой ключ Genosai → «Сохранить ключ».

Ключ **не хранится в коде** — он в личном профиле Google (UserProperties), каждый вводит свой.
Общий ключ команды можно положить в Свойства скрипта (`GENOSAI_API_KEY`) как запасной.

## Значения по умолчанию

Модель **ChatGPT Image 2**, качество **1K**, формат **16:9**, раскладка **на весь слайд**,
куда — **на текущий слайд**.

## Раскладки

| Раскладка | Что делает |
|---|---|
| На весь слайд | картинка «в обрез» на задний план; лишнее уходит за края. С заголовком — тёмная плашка снизу и белый текст |
| Справа / Слева | картинка в половине слайда, вторая половина под текст |
| Вписать по центру | картинка целиком, с полями |

Формат генерации подбирается автоматически: для полного слайда — ближайший к пропорциям вашей
презентации, для половины — вертикальный 3:4. Значение видно в подписи и переопределяется руками.

## Стиль

Четыре заводских стиля, каждый показан **картинкой-образцом** (одна и та же сцена, разный стиль —
видно, что получится):

| | Стиль | Что это |
|---|---|---|
| ![](assets/flat-thumb.jpg) | Флэт-иллюстрация | вектор, фиолет-малина, много воздуха |
| ![](assets/photo-thumb.jpg) | Фотореализм, мягкий свет | редакционное фото, мягкий свет из окна |
| ![](assets/clay-thumb.jpg) | 3D-пластилин | мягкий clay-рендер, пастель |
| ![](assets/line-thumb.jpg) | Линейная схема | тонкая линия, чертёжное ощущение |

Плюс «Без стиля». Описание стиля дописывается к каждому промпту как «соблюдать строго, одинаково
на всех кадрах», эталоны уходят в `image_urls`. Стиль задаёт модель и раскладку по умолчанию,
а выбранный стиль виден прямо на вкладке «Картинка».

Свои стили: **＋ Добавить эталон** — одна-две картинки задают визуальный язык надёжнее описания.
Хранятся в Script Properties (`GENOSAI_STYLES`).

## Сборка презентации

1. Тема и вводные, количество слайдов, текстовая модель, режим:
   **добавить в конец** или **создать с нуля** (старые слайды удаляются уже после сборки новых,
   с подтверждением).
2. Модель возвращает план: раскладка, заголовок, пункты, промпт картинки.
3. **План открывается прямо в сайдбаре и правится**: заголовки, пункты, промпты картинок, раскладка,
   лишние слайды можно убрать.
4. **«Вставить в презентацию»** — скрипт идёт по слайдам, рисует картинки в стиле и раскладывает их,
   показывая прогресс.

План на 6 слайдов через `gpt-5.4` — около 1 кредита. Если картинка не получилась, слайд остаётся
с текстом, а в конце пишется, сколько слайдов осталось без иллюстрации.

## Ограничения

- Размер слайда (16:9, 4:3) Apps Script менять не умеет — это **Файл → Настройки страницы**;
  скрипт подстраивается под текущий.
- Лимит 6 минут не задевается: слайды и картинки идут по одному, статус опрашивается с клиента.
- Скоуп `presentations.currentonly` — только та презентация, в которую вшит скрипт.
