# 🤖 AI Agent GenosAI для Google Документов и Google Презентаций

Два дополнения на Google Apps Script, которые приносят [Genosai](https://genosai.io) прямо в редактор:
генерация картинок всеми доступными моделями, тексты 23 языковыми моделями, шаблоны документов
и сборка презентаций целиком — из сайдбара, без переключения вкладок.

| | |
|---|---|
| **[google-docs](google-docs/)** | Картинки в место курсора, тексты с разметкой (заголовки, списки, таблицы), шаблоны документов: модель пишет КП и сама расставляет в нём картинки |
| **[google-slides](google-slides/)** | Картинки с раскладкой по слайду, сквозной визуальный стиль, сборка презентации: план правится в сайдбаре, потом уходит в слайды |

## Что нужно

- Аккаунт [Genosai](https://genosai.io) и API-ключ `sdk_live_…` (раздел API).
- Google Документ или Презентация, куда вшивается скрипт.

Ключ **не хранится в коде**. Каждый пользователь вводит свой через шестерёнку в сайдбаре — ключ
ложится в его личный профиль Google (UserProperties) и не виден другим соавторам файла. Для общего
ключа команды есть запасной вариант: Свойства скрипта, `GENOSAI_API_KEY`.

## Установка

Подробные шаги — в README каждой папки: [Документы](google-docs/README.md) ·
[Презентации](google-slides/README.md). Кратко:

1. **Расширения → Apps Script** в нужном файле.
2. Включить показ `appsscript.json` в настройках проекта.
3. Создать файлы с теми же именами, что в папке (имена со слэшем редактор покажет папками),
   и вставить содержимое.
4. Запустить `onOpen`, выдать разрешения, перезагрузить документ.
5. Сайдбар → **⚙** → свой ключ Genosai.

## Обновление без копипаста (clasp)

Чтобы не переносить файлы руками, есть [clasp](https://github.com/google/clasp) — CLI для Apps Script.
Разовая настройка:

```bat
npm i -g @google/clasp
clasp login
```

Плюс один раз включить Apps Script API: https://script.google.com/home/usersettings → «Google Apps Script API» → On.

Дальше в папке нужного дополнения:

```bat
clasp-init.bat ВАШ_SCRIPT_ID
push.bat
```

`SCRIPT_ID` берётся в редакторе: **⚙ Настройки проекта → Идентификатор скрипта**.
`clasp-init.bat` создаёт локальный `.clasp.json` (он в `.gitignore` — у каждого свой),
`push.bat` заливает проект в Google, `pull.bat` тянет обратно, если правили в браузере.

Заливаются только рабочие файлы: `appsscript.json`, `Code.gs`, `Sidebar.html` и скрипты по папкам.
README, `assets/` и сами `.bat` остаются локально — за это отвечает `.claspignore`.

## Стили презентаций

Четыре заводских стиля выбираются картинкой — одна сцена, разная подача:

| ![](google-slides/assets/flat-thumb.jpg) | ![](google-slides/assets/photo-thumb.jpg) | ![](google-slides/assets/clay-thumb.jpg) | ![](google-slides/assets/line-thumb.jpg) |
|---|---|---|---|
| Флэт-иллюстрация | Фотореализм | 3D-пластилин | Линейная схема |

Стиль дописывается к каждому промпту, поэтому все слайды держат одну палитру и подачу.

## Модели

Список тянется живьём из `/v1/models` вместе с ценой в кредитах, так что новые модели Genosai
появляются в сайдбаре сами. По умолчанию — ChatGPT Image 2, 1K, 16:9.
